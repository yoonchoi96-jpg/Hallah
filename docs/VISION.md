# Hallah Vision

## Mission

**Anyone can be the Executive Producer.**

Hallah lowers the technical barrier to professional music production without lowering the user's agency.

The system should meet the user at their level. A beginner can describe a feeling. An expert can specify a transient, note, voicing, timing, or frequency decision. Hallah translates either into executable production work.

## What Hallah is

An AI-native production environment where the user and an AI Executive Producer develop one song continuously.

The AI remembers musical identity, previous decisions, rejected and selected candidates, track relationships, production state, user preferences, and current problems and goals.

## What Hallah is not

- not a one-click song generator
- not a chatbot that only gives production advice
- not a fixed preset recommender
- not a DAW that happens to have an AI button

The defining feature is the closed loop between conversation, musical context, actual execution, audition, and user choice.

## Musical Authority

No source is automatically the boss of the entire song.

| Dimension | Possible authority |
|---|---|
| Harmony / mood | Guitar, piano, sample, user |
| Rhythm / groove | Drums, percussion |
| Melody / phrasing | Vocal, lead instrument |
| Low-end foundation | Bass |
| Texture / color | Any reference source |
| Arrangement direction | User + Executive Producer |

The hierarchy can change during the song.

## Executive Producer relationship

- User: taste, intent, judgment, final approval
- Hallah: listening, analysis, translation, execution, iteration, comparison, explanation
